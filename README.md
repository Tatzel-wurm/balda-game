# Балда

Мобильная браузерная версия игры «Балда» для 2–4 игроков или одного игрока против компьютера. Для компьютерного соперника доступны лёгкий, средний и сложный уровни: они отличаются длиной и качеством подбираемых слов. Приложение не требует сборки и работает офлайн: откройте `index.html` в браузере или из приложения «Файлы» на iPhone.

## Запуск

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Словарь

Полный список существительных разной длины хранится локально в `dictionary.js` и основан на проекте [appomsk/russian-words](https://github.com/appomsk/russian-words/blob/main/russian-nouns). Для стартового слова из списка выбираются только пятибуквенные варианты. Для проверки слов приложению не требуется доступ к сети.
