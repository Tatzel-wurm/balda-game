# Балда

Мобильная PWA-версия игры «Балда» для 2–4 игроков или одного игрока против компьютера. Для компьютерного соперника доступны лёгкий, средний и сложный уровни: они отличаются длиной и качеством подбираемых слов. Приложение устанавливается на экран «Домой» iPhone и после первого сетевого запуска работает офлайн.

## Запуск

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Установка на iPhone

1. Разместите приложение на HTTPS-хостинге и откройте его в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускайте «Балду» с экрана «Домой» как обычное приложение.

Service Worker кэширует интерфейс, словарь и иконки после первого открытия. При локальной разработке он также работает на `localhost`.

## Словарь

Полный список существительных разной длины хранится локально в `dictionary.js` и основан на проекте [appomsk/russian-words](https://github.com/appomsk/russian-words/blob/main/russian-nouns). Для стартового слова из списка выбираются только пятибуквенные варианты. Для проверки слов приложению не требуется доступ к сети.
